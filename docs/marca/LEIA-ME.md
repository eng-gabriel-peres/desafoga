# Marca do Desafoga

Gerada a partir do símbolo do app (`src/components/desafoga/marca.tsx`) e da fonte Nunito ExtraBold, com o texto convertido em contorno (os SVGs não dependem da fonte instalada). PNGs com fundo transparente: logos com 2000 px de largura, ícones com 1024 px.

| Arquivo | Uso |
|---|---|
| `logo-horizontal` | Cabeçalhos, slides, rodapés (fundo claro) |
| `logo-horizontal-escuro` | O mesmo, para fundo escuro |
| `logo-vertical` / `-escuro` | Espaços estreitos, capa de apresentação |
| `simbolo` / `simbolo-branco` | Só o símbolo |
| `icone-app` / `-claro` | Ícone de aplicativo |
| `icone-chat` / `-claro` | Foto de perfil do WhatsApp da Luana |

Cores: azul `#2350C8` (confiança, calma) e dourado `#E8B931` (alívio, esperança). Fundo escuro de referência: `#141E33`.
